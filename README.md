# EHR Mobile UI Design

A modern, user-friendly mobile interface for managing patient health records, designed in **Figma**.  
This project focuses on clean layouts, intuitive navigation, and accessibility to support healthcare professionals and patients.

---

## 📖 Overview
This repository contains the UI design for an **Electronic Health Record (EHR) mobile application**.  
The design emphasizes simplicity, usability, and a professional look to ensure healthcare data is easy to access and manage.

---

## 🎨 Features
- **Dashboard for patient records** – quick overview of health data
- **Appointment scheduling screens** – streamlined booking and reminders
- **Medical history and reports view** – organized and accessible records
- **Profile and settings management** – customizable user experience
- **Responsive mobile-first design** – optimized for smartphones

---

## 🛠️ Tools Used
- **Figma** – for UI/UX design
- **Modern design principles** – clean typography, accessible color palette, and intuitive layouts
